# 📱 Flutter + Firebase

Aplicación desarrollada en Flutter que integra Firebase Firestore como servicio de base de datos.
Se desarrolló una aplicación móvil en Flutter para la visualización y administración de un catálogo de películas. La aplicación integra Firebase Firestore como servicio de base de datos, permitiendo almacenar y consultar información de películas en tiempo real. Además, se implementaron pantallas de inicio, catálogo, detalle y administración, cumpliendo con los requerimientos funcionales establecidos.

## 🚀 Funcionalidad

* Conexión con Firebase
* Almacenamiento de datos en Firestore
* Interfaz Flutter funcional

## 🛠 Tecnologías utilizadas

* Flutter
* Dart
* Firebase
* Cloud Firestore
